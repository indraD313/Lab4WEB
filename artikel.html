Artikel Pembelajaran

Dasar-dasar yang digunakan dalam pembuatan layout website.

Memahami Box Element

Setiap elemen HTML dapat dipahami sebagai sebuah kotak. Box model terdiri dari content, padding, border, dan margin. Keempat bagian ini membantu mengatur ukuran serta jarak elemen.

Menggunakan CSS Float

Properti float dapat menempatkan elemen ke sisi kiri atau kanan sehingga elemen lain dapat mengalir di sekelilingnya. Properti clear digunakan untuk mengatur elemen agar tidak berada di samping elemen yang di-float.
