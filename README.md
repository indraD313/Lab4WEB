## Deskripsi
Project ini merupakan hasil Praktikum 4 Pemrograman Web tentang CSS Layout. Project ini bertujuan untuk memahami struktur layout website, Box Element, CSS Float, dan HTML Semantic Elements.

## Fitur
- Header dan navigasi.
- Hero section.
- Main content dan sidebar.
- Widget dan artikel.
- Footer.
- Penggunaan gambar dan tombol.

## Teknologi
- HTML5
- CSS3

## Struktur File
- `home.html` - Halaman utama website.
- `style.css` - Pengaturan tampilan dan layout website.

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka folder project.
3. Jalankan file `home.html` melalui browser.

## Tujuan Praktikum
Memahami penggunaan elemen HTML dan CSS untuk membuat layout website sederhana, termasuk penggunaan float, clear, dan elemen semantik HTML5.
